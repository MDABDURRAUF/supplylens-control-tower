How to read this

Estimated saving is what the model expected at decision time. Realized saving is the baseline cost minus the policy cost for the same orders, each played out in the simulated world with the same random luck. That comparison is possible only in a simulation. With real orders the baseline outcome of a changed order is never observed, so demonstrating savings would require a controlled comparison, such as keeping a random share of orders on the original plan. Each decision is evaluated independently; supplier capacity is not modelled.
